# call2text — расшифровка звонков на русском, локально на Mac

> Сделано для macOS на Apple Silicon (M1 и новее). Windows 10/11 — экспериментально, пока не проверено на живом компьютере. Linux не поддерживается.

Превращает запись звонка или встречи в текст с разметкой по собеседникам:

```
[00:12–00:31] Собеседник 1: Добрый день, давайте начнём с бюджета.
[00:32–00:40] Собеседник 2: Да, я подготовил цифры.
```

Всё работает на вашем компьютере: записи и расшифровки никуда не отправляются.
Из интернета скачиваются только модели при первом запуске.

- **Что сказали** — [GigaAM-v3](https://huggingface.co/ai-sage/GigaAM-v3) (вариант `e2e_rnnt`: с пунктуацией и нормализацией).
- **Кто говорит** — [pyannote](https://github.com/pyannote/pyannote-audio), модель `speaker-diarization-community-1`.
- Есть консольная команда и лёгкий веб-интерфейс: список звонков, поиск, видеоплеер с переходом по клику на реплику, переименование собеседников, правка текста, экспорт в `.txt` и `.md`.

Проект не связан с ПАО Сбербанк, SberDevices и авторами pyannote. Он только использует их открытые модели.

## Требования

- Mac на Apple Silicon (M1 и новее). Разметка собеседников идёт на видеокарте Mac (MPS), а интерфейс использует системный диалог выбора файла macOS.
- [Homebrew](https://brew.sh) — через него ставится FFmpeg, если его ещё нет.
- Бесплатный аккаунт на [HuggingFace](https://huggingface.co). Установщик откроет нужные страницы и подскажет, что сделать.

## Установка

```sh
curl -fsSL https://raw.githubusercontent.com/gvp013/call2text/main/install.sh | bash
```

Установщик сам поставит FFmpeg, Python 3.12 и библиотеки, создаст команды `call2text` и `calls-ui` и ярлык «Расшифровка звонков» на рабочем столе. Он попросит токен HuggingFace, проверит доступ к моделям pyannote и по желанию сразу скачает модели (~1,5 ГБ). Первая установка занимает несколько минут.

**Windows (экспериментально)** — в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/gvp013/call2text/main/install.ps1 | iex"
```

Нужны 64-битная Windows 10/11 и winget (есть в Windows 11, в Windows 10 — «Установщик приложений» из Microsoft Store). С видеокартой NVIDIA разметка собеседников идёт на ней, без неё — на процессоре, в несколько раз медленнее. Программа ставится в папку `call2text` в домашней папке, на рабочем столе появляется ярлык «Расшифровка звонков».

Повторный запуск обновляет программу. Если проект уже скачан, можно запустить `./install.sh` из его папки.

## Использование

Консоль:

```sh
call2text запись.webm --speakers 2     # результат — запись.txt рядом
call2text запись.mp4 --no-merge -o out.txt
```

- `--speakers N` — сколько собеседников, если известно (разметка заметно точнее).
- `--no-merge` — не склеивать соседние реплики одного собеседника (по умолчанию склеиваются при паузе < 1 с).

Интерфейс:

```sh
calls-ui        # откроет http://127.0.0.1:8790
```

Сервер слушает только `127.0.0.1`, снаружи он недоступен. База звонков лежит в `data/calls.db`, записи не копируются: интерфейс хранит путь к исходному файлу и показывает видео прямо из него.

Скорость на M-серии: 15-минутный звонок — около 2,5 минут.

## Ответственность за записи

Программа только расшифровывает файлы, которые у вас уже есть. За законность записи разговоров, обработки персональных данных собеседников и распространения расшифровок отвечает пользователь. Перед публикацией или передачей расшифровок третьим лицам убедитесь, что у вас есть на это право (в России — ст. 23 Конституции, ст. 152.2 ГК РФ, 152-ФЗ «О персональных данных»).
